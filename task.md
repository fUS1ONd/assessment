# Задача

Задача для третьего и четвёртого курсов:

В файле задан ориентированный граф в виде матрицы инцидентности. Напишите программу, определяющую, есть ли в графе вершины, достижимые из всех других вершин.

## Требования к решению

От решения задачи ожидается:

- соблюдение принятого для выбранного языка стиля кодирования;
- модульные тесты или хотя бы несколько примеров запуска (настоящие модульные тесты принесут больше баллов, особенно для 3 курса и выше);
- комментарии к каждому публичному методу (функции) и классу (модулю).

Решение желательно оформить пулл-реквестом в собственный репозиторий из отдельной ветки для задачи.
