# Вершины, достижимые из всех других

Условие задачи лежит в [task.md](task.md).

## Формат входного файла

Граф задаётся матрицей инцидентности. В первой строке файла два числа: `n` (сколько вершин) и `m` (сколько рёбер). Потом идут `n` строк по `m` чисел через пробел. Строки соответствуют вершинам, столбцы рёбрам. Вершины нумеруются с нуля.

В каждом столбце у вершины, из которой выходит ребро, стоит `-1`, у вершины, в которую оно входит, стоит `1`, а у остальных `0`. Петлю обозначаем числом `2`.

Пример для графа `0 → 1`, `1 → 2`, `2 → 1`:

```
3 3
-1  0  0
 1 -1  1
 0  1 -1
```

Ответ: вершины `1` и `2`, до них можно дойти из любой другой.

Если размеры матрицы не совпадают с `n` и `m`, в ней есть числа кроме `-1`, `0`, `1`, `2` или какой-то столбец не похож на одно ребро, программа сообщит об ошибке.
